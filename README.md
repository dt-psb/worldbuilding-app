# 🪐 WorldBuilding App (세계관 빌더) 사용 설명서 & 기능 가이드

> **WorldBuilding App**은 소설, 웹툰, 게임 시나리오, TRPG 창작자를 위한 **데스크톱 기반 통합 세계관·인물 서사 관리 프로그램**입니다.  
> 인물들의 복잡한 심리와 관계망, AI로 생성한 장문의 서사 본문, 에피소드 출연 통계를 한눈에 시각화하고, 옵시디언(Obsidian)과 완벽히 연동할 수 있습니다.

## 1. 빠른 시작 (실행 방법)

### 방법 A. 전용 프로그램으로 바로 실행 (가장 권장)
- 프로젝트 폴더의 **`WorldBuilding.exe`**를 더블 클릭합니다.
- 검은색 콘솔(cmd) 창이 전혀 뜨지 않고 순수한 데스크톱 앱 형태로 즉시 구동됩니다.

### 방법 B. 배치 파일 실행
- **`start.bat`**을 더블 클릭합니다.
- 내부적으로 무창 실행기를 구동한 후 배치 창은 즉시 자동으로 닫힙니다.

### 방법 C. Node.js 개발 환경 실행
```bash
npm install
npm start
```

* 모든 데이터는 사용자 PC 내부 로컬 SQLite DB(`%APPDATA%/worldbuilding/worldbuilding.db`)에 영구 보존되므로 인터넷 연결 없이도 완전히 독립적으로 동작합니다.

## 2. UI & 창 제어 (무창 실행 & 커스텀 타이틀바)

- **프레임리스(Frameless) 모던 디자인**: 투박한 시스템 기본 제목 표시줄을 제거하고 세련된 상단 일체형 타이틀바를 제공합니다.
- **창 컨트롤 버튼 세트**:
  - `─` **최소화**: 창을 작업표시줄로 최소화합니다.
  - `□` / `❐` **최대화 / 복원**: 창을 전체화면으로 확대하거나 원래 크기로 복원합니다.
  - `✕` **닫기**: 마우스 호버 시 윈도우 스타일 레드 하이라이트가 적용되며 앱을 안전하게 종료합니다.
- **창 이동 & 조작**: 상단 타이틀바 영역을 마우스로 잡고 드래그하여 창을 이동할 수 있으며, 빈 공간을 **더블 클릭하면 최대화 및 이전 크기로 복원**이 토글됩니다.
- **다크 / 라이트 테마**: 사이드바 하단의 `[🌙 다크]` / `[☀️ 라이트]` 버튼으로 테마를 전환할 수 있습니다.

## 3. 캐릭터 관리 (Characters)

인물 카드를 그리드 또는 리스트 형태로 모아보고, 클릭하여 상세 프로필을 열람하거나 편집할 수 있습니다.

### 기본 정보 & 세력 배속 & 상태 표시
- **이름, 나이, 성별, 키(cm)**를 기록합니다.
- 소속 세력(Faction)을 복수로 지정할 수 있으며 고유 컬러 배지가 표시됩니다.
- **생사/상태 표시**: 생존, 사망, 행방불명 등 인물의 상태를 표시하며, 직접 입력 시에도 깔끔한 파란색 원형 뱃지로 균일하게 정돈되어 표시됩니다.

### 메인 프로필 & 자유 추가 프로필
- **메인 프로필**: 캐릭터마다 필수로 갖추는 기본 공개 프로필입니다. (외모, 성격, 배경 이야기 등을 마크다운으로 자유롭게 작성)
- **추가 프로필 (+버튼)**: 비밀 프로필, 과거 프로필, IF 프로필 등 필요한 만큼 프로필 탭을 무제한 생성할 수 있습니다.
  - 탭 명칭을 사용자가 직접 수정할 수 있습니다.
  - 각 프로필마다 **[📋 복사]** 버튼이 개별 제공되어 클립보드에 원클릭 복사할 수 있습니다.

### 그 외 정보 (과거사 / 인물관계 / 능력 등 커스텀 블록)
- 캐릭터 상세 정보에 옵시디언이나 메모장에서 가져온 서사를 붙여넣을 수 있는 **자유 커스텀 정보 블록**입니다.
- 버튼 하나로 블록을 추가하고 제목(예: *과거사, 전투 능력, 특이사항 등*)을 지정할 수 있으며, 각 블록마다 독립된 **[📋 복사]** 버튼이 지원됩니다.

### 이미지 갤러리 & 라이트박스 & 아바타 크롭
- 캐릭터 일러스트나 설정화를 여러 장 등록하고 대표 아바타를 손쉽게 원형/사각형으로 **크롭(자르기)**할 수 있습니다.
- 이미지를 클릭하면 고화질 **라이트박스 뷰어**가 열립니다 (방향키로 이전/다음 탐색 가능).

### 신장(키) 비교 차트 & 캐릭터 카드 PNG 내보내기
- **[📏 키 비교]**: 등록된 캐릭터들이 키 순서대로 서 있는 직관적인 신장 비교 바 차트를 확인합니다.
- **[🖼️ 카드 내보내기]**: 대표 아바타와 핵심 프로필이 담긴 미려한 **PNG 캐릭터 프로필 카드**를 생성하여 저장하거나 클립보드로 복사합니다.

## 4. 캐릭터 간의 관계 & 서사 (Relations)

두 인물 사이의 감정선, 역사, AI로 생성한 장문의 관계 서사(2000자 이상)를 관리합니다.

### 양방향 vs 단방향 관계 설정
1. **⟷ 양방향 상호 관계 (동등한 관계)**: 두 인물이 서로 동의하고 공유하는 관계 (동료, 연인, 가족, 라이벌 등).
2. **➔ 단방향 / 개별 관계 (A➔B, B➔A)**:
   - 각자가 상대를 바라보는 시선이 다를 때 사용 (예: A는 짝사랑, B는 무관심).
   - 한쪽이 상대방을 모르는 경우 `(지정 안 함 / 모름)`을 선택하면 의식하는 방향의 **단일 화살표**만 생성됩니다.

### 직접 입력 & 8대 기준 색상 팔레트
- 기본 제공 관계 외에 특수한 관계를 직접 입력할 수 있습니다.
- 직접 입력 시 **8가지 기준 색상 팔레트** 중 하나를 선택해 관계의 톤앤매너를 일관되게 맞출 수 있습니다.

### 관계 서사 리더 (Narrative Viewer) & 시점 안내
- 두 인물을 선택하면 긴 관계 서사 본문을 마크다운 뷰어로 바로 읽을 수 있습니다.
- 상단에 *"해당 관계는 세계관 시작 시점의 관계입니다"* 안내 문구가 명시되어 에피소드 진행에 따른 관계 변화와 구분됩니다.
- 우측 버튼을 통해 해당 인물 간의 집중 관계 그래프 모드로 즉시 이동할 수 있습니다.

## 5. 인터랙티브 관계 그래프 (Graph)

D3 Force 시뮬레이션 알고리즘과 고성능 HTML5 Canvas를 결합하여 수백 명의 인물도 부드럽게 시각화합니다.

### D3 Force + HTML5 Canvas 시뮬레이션
- 마우스 휠로 Zoom, 드래그로 Pan, 노드를 끌어서 원하는 물리 배치로 고정할 수 있습니다.
- 특정 세력이나 특정 관계 유형만 골라 필터링할 수 있습니다.

### 2중 단방향 곡선 및 화살표 렌더링
- 서로 다른 단방향 관계를 가질 때 선과 텍스트가 겹치지 않도록 **2차 베지에 곡선(Bezier Curve)**으로 반대편으로 벌어져 렌더링됩니다.
- 각 곡선 끝에 화살표와 독립 배지(`➔ 짝사랑`, `➔ 경계`)가 표시됩니다.

### 🎯 특정 인물 중심 집중 모드 (1촌 / 2촌)
- 노드를 더블 클릭하여 해당 인물과 연결된 사람만 화면에 남기는 집중 모드를 켭니다.
- **[1촌만]**: 직접 관계 인물만 표시
- **[2촌까지]**: 지인의 지인까지 2단계 확장 표시

### 🔍 인맥 최단 경로 탐색기 (Pathfinder)
- 인물 A와 인물 B 사이의 **최단 인맥 징검다리 경로**를 BFS 알고리즘으로 찾아내 네온 하이라이트로 연결선을 비춰줍니다.
- **🏰 소속 세력 연계 탐색 (신규)**:
  - 직접적인 인물 관계가 없더라도, **동일한 세력에 소속되어 있다면 해당 세력을 하나의 연결 고리로 취급**하여 최단 경로를 탐색합니다.
  - 임의로 건너뛰는 방식이 아닌, 탐색 경로 및 그래프 상에 **실제 세력 노드(Faction Node, 🏰 방패 배지)**를 생성하여 경유합니다.
  - 해당 세력에 소속된 경로 상의 캐릭터들뿐만 아니라, **화면에 존재하는 동일 세력 소속 캐릭터들도 모두 해당 세력 노드와 연결선으로 결합**되어 세력 중심의 유기적인 인맥 네트워크를 한눈에 확인할 수 있습니다.

## 6. 세력 관리 (Factions)

- 국가, 가문, 기사단, 길드, 학원, 비밀 결사 등 세계관 내 조직을 관리합니다.
- 세력명, 대표 색상, 개요 및 상위 세력을 설정할 수 있으며, 세력 클릭 시 소속 인물 목록이 모여 표시됩니다.

## 7. 에피소드 관리 (Episodes)

작품의 회차(1화, 2화...), 사건, 퀘스트별 기록을 관리하고 인물들의 출연 통계를 집계합니다.

### 주연 / 조연 / 엑스트라 / 언급 인물 분류
- **주연 (Main)**: 스토리의 중심축을 이끄는 인물
- **조연 (Sub)**: 사건을 보조하는 비중 있는 인물
- **엑스트라 (Extra)**: 일회성 단역 인물 (에피소드 내 즉석 추가)
- **이름으로만 언급되는 캐릭터**: 서사에 직접 등장하지는 않았지만 대사나 설정상 언급된 인물들을 정리 (등장 통계에는 취급되지 않아 데이터가 오염되지 않음)

### 에피소드 내 인물 프로필 즉시 보기
- 에피소드 상세 화면에서 주요 등장인물을 클릭하면, 에피소드를 벗어나지 않고 해당 인물의 상세 프로필을 모달로 즉시 열람할 수 있습니다.
- 상단 **[뒤로가기]** 버튼을 통해 원래 읽던 에피소드로 즉시 돌아갈 수 있습니다.

### 출연 통계 & 🎲 옴니버스 소재 조합기
- 캐릭터별 총 에피소드 출연 횟수가 자동 집계되며, 미등장 캐릭터 필터를 지원합니다.
- **[🎲 옴니버스 소재 조합기]**: 출연 빈도가 적은 인물과 주연 인물을 무작위로 매칭하여 새로운 서사 아이디어를 착상할 수 있도록 키워드를 추천합니다.

---

## 8. 생일 달력 (Calendar)

- 캐릭터들의 생일을 월별 캘린더 형태로 시각화하여 기념일과 나이 계산을 지원합니다.

---

## 9. 데이터 안전 & 옵시디언(Obsidian) 연동

### 이미지 보관 방식 (용량 최적화)
- 앱에 등록하는 이미지는 파일을 복사하지 않고 **PC의 파일 경로만 DB에 참조**하므로, 수백 장의 고화질 이미지를 등록해도 DB 용량이 가볍게 유지됩니다.

### 옵시디언 마크다운 볼트 내보내기
- **[📁 폴더 선택]** 후 **[🚀 옵시디언 볼트로 전체 내보내기]**를 클릭하면 옵시디언 표준 마크다운 문서가 자동 생성됩니다:
  - `Characters/`: 캐릭터별 `.md` (YAML Frontmatter 메타데이터, 프로필 서사, 관계망)
  - `Relationships/`: `[캐릭터A] - [캐릭터B].md` 형태의 2000자 관계 서사 문서
  - `Episodes/`: 사건 요약 및 `[[인물 위키링크]]`가 포함된 문서
  - `Factions/`: 세력 설명 및 소속 인물 링크
  - `_WorldBuilding_Home.md`: 볼트 전체 인덱스 대시보드
- 모든 연결고리가 `[[위키링크]]` 문법으로 기록되어 옵시디언 자체 **그래프 뷰(Graph View)**에서도 관계망이 유기적으로 연결됩니다.

### 자동 스냅샷 & 백업 / 복원
- **앱 시작 시 자동 스냅샷**: 앱을 실행할 때마다 `%APPDATA%/worldbuilding/backups/`에 스냅샷이 자동 저장됩니다 (최신 15개 롤링 유지).
- **[💾 새 백업 파일 저장]**: 수동 단일 `.db` 파일 백업.
- **[📥 백업 파일로 복원]**: 과거 스냅샷이나 외부 백업 파일로부터 원클릭 데이터 복원.

### JSON 데이터 내보내기 / 가져오기
- SQLite 파일 외에도 범용 JSON 포맷(`worldbuilding_export.json`)으로 내보내거나 가져올 수 있습니다.

## 10. 오류 로그 수집 시스템 (`logs/`)

프로그램의 안정적인 동작을 위해 런타임 예외와 에러를 자동으로 수집합니다:
- **`logs/app_YYYY-MM-DD.log`**: 일자별 전체 실행 흐름 및 경고/에러 기록.
- **`logs/error.log`**: 긴급 확인을 위해 치명적 에러(ERROR / FATAL)만 모아 기록.
- 메인 프로세스(Node.js)의 치명적 예외와 렌더러(웹 UI)의 자바스크립트 런타임 오류가 양방향으로 자동 기록되어 문제 발생 시 빠른 원인 파악이 가능합니다.
